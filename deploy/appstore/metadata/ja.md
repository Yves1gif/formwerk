## Description
<!-- 963/4000 characters -->
```
3Dプリンターで出力する本物のパーツを、iPad、Mac、そして開いたiPhone Duoでそのまま設計。Formwerkは無料で使える精密なCADアプリです。スケッチを描き、押し出し、角を丸めて、スライサーへ送るだけ。
アカウント不要、サブスクなし、トラッキングなし。データはすべてあなたのデバイスの中に。
操作しながら覚えるチュートリアルで、10分後には最初のプリントへ。いつでもスキップできます。

アイデアからプリントまで
• 寸法と拘束付きのスケッチ
• 押し出し、回転、プッシュ/プル、フィレット、面取り、穴（M2〜M8）、文字、ミラー、結合
• 編集できる履歴：どのステップも後から変更でき、パーツが自動で更新
• OpenCascadeカーネルによる精密なソリッド。メッシュではありません

すぐにプリントできる
• 印刷チェック：閉じたソリッド、オーバーハング、薄い壁、ベッドサイズ
• 平置き：面をタップするとベッドにぴったり
• フィラメント使用量の目安
• どのスライサーでも使えるSTL書き出し（無料）

テンプレートから始める
キーホルダー、ボックス、壁用ブラケット、植木鉢、スマホスタンド、壁フック。どのテンプレートも普通のステップでできているので、すべて自由に変更できます。

Appleデバイスのために
• Apple Pencilに対応。Apple Pencil Proのスクイーズとホバーにも対応
• 指、マウス、トラックパッド、キーボードショートカット
• iPhone Duo：大きな内側の画面でフル機能のエディタ
• iCloud Driveや好きなフォルダに保存
• 16言語に対応

FORMWERK PRO：買い切り、サブスクなし
ここまでの機能はすべて無料。たくさんプリントする人は、Formwerk Proを一度購入するだけで次の機能が使えます：
• 3MF、STEP、OBJ、USDZ書き出し
• STEP読み込み
• 実寸大のAR表示
• 最適な向きを自動で決める自動配置
• パターン、シェル（中空化）、分割ツール

オープンでプライベート
Formwerkはオープンソース（MPL-2.0）。アカウントなし、広告なし、データ収集なし。すべてデバイス上で動作します。
```
